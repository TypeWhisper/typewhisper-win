# Plugin navigation logos

These assets are bundled with the host; plugin packages do not need to provide new metadata.

- Groq, OpenAI and OpenRouter: copied from the TypeWhisper website's `public/brand-logos` directory.
- GitHub Copilot: [GitHub Primer Octicons, copilot-24](https://github.com/primer/octicons/blob/main/icons/copilot-24.svg), SVG blob `201ecf408786f8e248ed4a223262c11c6eb726c0`. Licensed under [MIT](Octicons-LICENSE.txt); explicit light/dark fill colors added for native rendering.
- Deepgram, ElevenLabs and NVIDIA: [Simple Icons](https://github.com/simple-icons/simple-icons), distributed under [CC0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).
  Source SVG blob IDs: Deepgram `31579cb31bcd948a78c76bc1ae3266917cb979bb`, ElevenLabs `bad5cfb9d03da69f22980499dcc529c3d1a7dcc0`, NVIDIA `2c7ff66f8b1f04c24df0d4653f665cd97a228c92`.

Explicit fill colors support native SVG rendering. Monochrome marks include light and dark variants. Brand names and marks belong to their respective owners.
