# UI evidence

Subdirectories contain screenshots and, where available, companion acceptance
notes for particular plugin or UI changes. They are evidence snapshots, not a
complete or necessarily current visual specification.

Provider notes: [AssemblyAI](assemblyai/README.md), [Cerebras](cerebras/README.md),
[Claude](claude/README.md), [live text](live-text/README.md),
[Qwen3 Local](qwen3-local/README.md).

When adding evidence, identify the tested source/build, profile, scenario and
limits in its owning guide. Use synthetic text and exclude credentials and private
transcripts. Keep product instructions in the [main documentation](../README.md).
