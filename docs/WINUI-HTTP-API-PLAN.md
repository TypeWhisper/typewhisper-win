# WinUI HTTP API

The HTTP API is implemented by the WinUI host and its presentation layer. The former WPF server and integration are removed.

Use the [API reference](WINUI-HTTP-API.md) and [CLI guide](WINDOWS-CLI.md) for the current contract. Automated coverage lives in `tests/TypeWhisper.Presentation.Tests` and `tests/TypeWhisper.Cli.Tests`; native lifecycle and request probes live in `tests/native`.
