TypeWhisper 1.2.1 исправляет две ошибки версии 1.2.

- Сочетание клавиш без Ctrl, Alt или Shift снова может использовать Insert, Pause, а также мультимедийные клавиши, клавиши громкости и браузера. Раньше без модификатора работали только F1–F24.
- В поле токена Hugging Face для Cohere Transcribe (Local) и Supertonic TTS пометка «(optional)» теперь отображается только один раз.
