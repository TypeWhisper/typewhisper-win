# Open issue triage for the Windows 1.1 Daily

Reviewed all 20 open issues on 2026-09-10 against the release-preparation checkout. These are implementation/validation decisions, not issue closure claims. Reports against the old WPF host must be reproduced in WinUI before calling them resolved. Six primarily concern plugins, acceleration, or plugin deployment; fourteen concern the application or larger product features.
