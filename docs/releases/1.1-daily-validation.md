# WinUI Daily validation: update channels and on-demand plugins

## Build and scope

Validated the PR #452 candidate from GitHub Actions run 34461775686 (PR merge commit `43b98502d1d761014ed0acf268b15cbb7bbcf3e1`, version `1.1.0-daily.20260910.8`). Both x64 and ARM64 release packaging passed. This candidate has not been published as a Daily release.

## Package measurements

ARM64 setup: 222,263,045 bytes before, 159,675,920 bytes after (212.0 to 152.3 MiB, approximately 28% smaller). The previous comparison candidate is `1.1.0-daily.20260910.5`.

x64 setup: 230,632,336 bytes before (published Daily `.6`), 167,570,067 bytes after (219.95 to 159.81 MiB, 60.14 MiB / 27.3% smaller). Its candidate payload is 120.87 MiB compressed for the app/runtimes plus 35.32 MiB for the CLI. SHA-256 verification passed for the x64 candidate, setup and full update package.

The compressed candidate payload contains 114.94 MiB of app/runtime files and 33.73 MiB of CLI files, with no bundled plugin directory. Previous bundled plugins occupied 49.95 MiB compressed. Removing the WinForms dependency also reduced the app/runtime payload.

SHA-256 verification passed for the downloaded ARM64 candidate and setup. Hashing the decompressed files found 186 CLI files identical to app-root files: 86.15 MiB unpacked / 33.56 MiB compressed. These are potential packaging savings; the CLI currently needs a complete independent runtime when installed and must not simply lose these files.

## Fresh profile

An isolated development profile installed Parakeet through the live portable catalog, downloaded the TDT model, activated it and reached the wizard test field. Marco confirmed successful dictation using Ctrl+Shift+F9. The normal development profile was restored afterwards.

The walkthrough found a startup race: the wizard could retain its install button after the plugin index finished loading. The follow-up fix hides the installation section when the package becomes available. The local helper build passed after the fix.

## Update behavior

15 update-controller tests passed, including blocked restart during recording, explicit downgrade messaging, failed download, stale-offer invalidation and download-before-shutdown ordering. Six GitHub release-source tests, 31 plugin-store tests and seven package rejection checks also passed.

The follow-up also changes the default dictation shortcut to Ctrl+Shift in the startup fallback, settings and wizard, using one shared constant. Existing persisted shortcuts remain unchanged. All 17 hybrid-hotkey tests (including modifier-only chords) passed together with the 15 update-controller tests. The helper build/start passed. These follow-ups were made after the measured CI candidate; their next CI run must pass before publication.

A live installed-app update has not been completed: the published Daily predates the updater, and a subsequent compatible Daily containing the updater is needed. Release builds use the production profile even from a separate directory. Windows Sandbox is unavailable on this machine, so no isolated clean-machine installer acceptance is claimed. ARM64 native payload headers were verified; ARM64 hardware execution remains untested.
