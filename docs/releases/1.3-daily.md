# TypeWhisper 1.3 — Daily channel

Daily builds come from `main` and lead to TypeWhisper 1.3. They contain the newest changes, including features that are not finished yet. TypeWhisper 1.2 continues separately: its release candidates, Stable and 1.2.x fixes are published from the `release/1.2` branch, and every fix also reaches the Daily.

## Installation and updates

Use the x64 installer. Setup installs the required .NET 10 runtime when missing. The portable ZIP requires that runtime separately. The configured Windows minimum is build 19041. There is no ARM64 build; Windows 11 on Arm can run the x64 version through emulation, which is untested.

Daily installations update from 1.2 Daily builds to 1.3 Daily builds like any other Daily. The original 1.0 Daily and the separately installed early 1.1 Daily keep their different internal installation identities and feeds; the separate one receives Daily builds only. TypeWhisper checks for updates in the background; Account & about and the tray check on demand. Release candidates and Stable are published separately and install as the original TypeWhisper.

## Your existing data

Existing profiles are kept as they are. On the first start without a profile, TypeWhisper still imports a 1.0 profile; see [Daily migration and validation](../DAILY-1.1-CANDIDATE.md) for the exact scope. The original profile remains unchanged.
