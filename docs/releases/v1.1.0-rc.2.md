# TypeWhisper v1.1.0-rc.2

TypeWhisper 1.1.0-rc.2 is the second release candidate for Windows 1.1. The
[rc.1 release notes](https://github.com/TypeWhisper/typewhisper-win/releases/tag/v1.1.0-rc.1)
describe what is new in 1.1 and how the upgrade from 1.0 works.

## Changes since rc.1

- Integrations in Advanced settings lists the Raycast extension and the browser
  extension for Chrome and Firefox, each with a short explanation and a button,
  as in TypeWhisper for macOS. (#647)
- The command-line tool shows where it is installed, and its PowerShell
  examples follow the macOS examples with a copy button per command. (#647)

## Fixes since rc.1

- Script Runner no longer marks a saved script as changed when its settings
  open. Leaving the page no longer asks to discard changes, and saving no longer
  adds a line break to the end of the command. (#648)

## Updating

- rc.1 offers rc.2 through the update notice. Download and restart installs it
  and keeps the profile, plugins and settings.
- Installations of TypeWhisper 1.0 on the release-candidate channel update to
  rc.2 directly and import their existing data on the first start.
- 1.0 installations on the Stable channel stay on 1.0.9 until 1.1.0 is
  published.

## Installation and requirements

- The installer and portable ZIP are available for x64. Setup installs the
  .NET 10 runtime when it is missing; the portable ZIP requires it separately.
- TypeWhisper requires Windows 10 build 19041 or later.
- As with rc.1, the GitHub installers are not code-signed, so Windows
  SmartScreen may ask for confirmation. The Microsoft Store version is updated
  separately.

## RC validation notes

- Update rc.1 to rc.2 through the update notice and check the restart,
  shortcuts, license, profile, plugins and dictation.
- Open a saved script in Script Runner, leave the page and open it again: no
  unsaved-changes marker, no discard prompt and no added line break.
- In Advanced settings, check the Raycast and browser extension buttons, the
  installed command-line tool path and the copy buttons of the examples.
