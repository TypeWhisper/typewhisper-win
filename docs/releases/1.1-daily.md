# TypeWhisper 1.1 — Daily channel

This prerelease introduces the rebuilt interface, portable plugins, configurable shortcuts, workflows and the local HTTP API/CLI. The app and its executable are now consistently named **TypeWhisper** and **TypeWhisper.exe**. Daily remains the update channel.

## Installation and updates

Use the x64 installer. Setup installs the required .NET 10 runtime when missing. The portable ZIP requires that runtime separately. The configured Windows minimum is build 19041; native acceptance on older Windows remains pending. There is no ARM64 build; Windows 11 on Arm can run the x64 version through emulation, which is untested.

The original 1.0 Daily and the separately installed early 1.1 Daily have different internal installation identities. Update packages preserve the identity already installed: the original Daily updates through its 1.0 feed, and the separate 1.1 Daily keeps its own feed and receives Daily builds only. TypeWhisper checks for updates in the background; Account & about and the tray check on demand. Release candidates and Stable are published separately and install as the original TypeWhisper.

## Your existing data

On the first start without an existing 1.1 profile, TypeWhisper copies dictionary entries, snippets, workflows and history text, converts supported recording and text preferences, preserves license credentials, transfers plugin settings and encrypted API keys, installs compatible portable plugins, and copies available model assets. The original profile remains unchanged. A failed migration can be retried.

Existing 1.1 profiles are kept as they are. Account sign-ins, archived recordings/audio, recovery audio and settings without a matching 1.1 implementation remain in the old profile. Missing providers are reported; TypeWhisper does not silently replace your selected provider. Internet access is needed to install migrated plugins.

See [Daily migration and validation](../DAILY-1.1-CANDIDATE.md) for the exact scope, rollout gate and required installed-upgrade tests. Returning to 1.0 uses its preserved profile; new 1.1 changes are not copied back automatically.
