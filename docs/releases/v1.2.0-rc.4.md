# TypeWhisper v1.2.0-rc.4

TypeWhisper 1.2.0-rc.4 is the fourth release candidate for Windows 1.2. The
[rc.1 release notes](https://github.com/TypeWhisper/typewhisper-win/releases/tag/v1.2.0-rc.1)
describe what is new in 1.2, including managed settings for organizations and the
machine-wide MSI.

## Fixes since rc.3

- Local speech engines that run in the separate transcription worker, such as
  Parakeet, whisper.cpp and Qwen3, no longer fail when they load a component after
  the worker has been running for a while. The worker let go of the plugin it was
  still using, and the next component load ended with "An operation is not legal in
  the current state". (#696)

## Updating

- rc.3 offers rc.4 through the update notice. Download and restart installs it and
  keeps the profile, plugins and settings.
- Installations of TypeWhisper 1.1 on the release-candidate channel update to rc.4
  directly.
- Installations on the Stable channel stay on 1.1.0 until 1.2.0 is published.

## Installation and requirements

- The per-user installer, the MSI and the portable ZIP are available for x64. Setup
  installs the .NET 10 runtime when it is missing; the portable ZIP requires it
  separately. The Group Policy templates are attached as
  `TypeWhisper-win-PolicyTemplates.zip`.
- TypeWhisper requires Windows 10 build 19041 or later.
- As with rc.3, the GitHub installers, including the MSI, are not code-signed, so
  Windows SmartScreen may ask for confirmation. The Microsoft Store version is updated
  separately.

## RC validation notes

- Update rc.3 to rc.4 through the update notice.
- Dictate with Parakeet, which runs in the transcription worker, and check that it
  still transcribes after the app has been idle for a while.
