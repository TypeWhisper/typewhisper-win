# TypeWhisper v1.2.1

TypeWhisper 1.2.1 fixes two issues in 1.2.0. The
[1.2.0 release notes](https://github.com/TypeWhisper/typewhisper-win/releases/tag/v1.2.0)
describe what is new in 1.2, including managed settings for organizations and the
machine-wide MSI.

## Fixes

- A shortcut without Ctrl, Alt or Shift can again use Insert, Pause or a media,
  volume, browser or launch key, as in TypeWhisper 1.0. Since 1.1 only F1–F24 worked
  alone, which made push-to-talk awkward on laptops whose F-keys need Fn. Keys that
  type or edit text, toggle a lock or are used by Windows itself still need a
  modifier, and the message now lists the keys that work alone. A single Insert
  shortcut carried over from 1.0 registers again after the update. (#700)
- The Hugging Face token field of Cohere Transcribe (Local) and Supertonic TTS shows
  "(optional)" once instead of twice. (#703)

## Documentation

- The [managed settings guide](https://github.com/TypeWhisper/typewhisper-win/blob/main/docs/enterprise/windows-managed-settings.md)
  lists the hosts from which the Granite Speech plugin downloads its Python runtime.
  `AllowModelDownloads` = 0 blocks this runtime download together with the model.
  (#702)

## Updating

- 1.2.0 installations are offered 1.2.1 through the update notice. Download and
  restart installs it and keeps the profile, plugins and settings.
- Installations of TypeWhisper 1.1 and 1.0 update to 1.2.1 directly, as described in
  the 1.2.0 release notes.
- Machine-wide installations are updated by deploying the 1.2.1 MSI.
- The Microsoft Store version is updated separately.

## Installation and requirements

- The per-user installer, the MSI and the portable ZIP are available for x64. Setup
  installs the .NET 10 runtime when it is missing; the portable ZIP requires it
  separately. The Group Policy templates are attached as
  `TypeWhisper-win-PolicyTemplates.zip`.
- TypeWhisper requires Windows 10 build 19041 or later.
- As with 1.2.0, the GitHub installers, including the MSI, are not code-signed, so
  Windows SmartScreen may ask for confirmation.
