# TypeWhisper v1.2.0-rc.1

TypeWhisper 1.2.0-rc.1 is the first release candidate for Windows 1.2. Organizations
can now manage TypeWhisper centrally: machine policies set through Group Policy,
Intune or any tool that writes the registry control the license, providers, cloud
processing, downloads, updates and startup. A new MSI installs the app for every user
of a device. Installations of TypeWhisper 1.1 on the release-candidate channel update
in place.

## Managed settings for organizations

- TypeWhisper reads machine policies from `HKLM\SOFTWARE\Policies\TypeWhisper`
  (enforced) and its `Recommended` subkey (defaults users can change). Without policy
  values nothing changes. The app applies policy changes while it runs.
- `ManagedLicenseKey` activates a commercial license for each Windows user who starts
  TypeWhisper, with the same name and behavior as on macOS. While the key is managed,
  the Premium page hides key entry, deactivation and purchase links.
- Transcription and text models can be enforced or recommended as provider and model
  pairs. Allowlists limit the transcription providers, text providers and plugins.
- `AllowCloudTranscription` and `AllowCloudTextProcessing` keep audio and text on
  local plugins. Every plugin now declares whether it runs locally, in the cloud or
  depending on its configuration.
- `AllowPluginDownloads` and `AllowModelDownloads` stop plugin installs and updates
  from the catalog and the model downloads the app starts.
- `UpdateMode`, `UpdateChannel` and `AllowedUpdateChannels` control app updates;
  `LaunchAtLogin`, `SkipOnboardingWhenReady` and `SuppressOptionalPrompts` control
  startup, setup and the Premium prompt.
- Restrictions apply to dictation, file transcription, workflows, recovery and the
  HTTP API, which answers `403 forbidden`. Pickers, plugin pages and Integrations show
  why an entry is unavailable.
- Settings > Advanced > Managed settings lists the effective values and any problems.
  The support report contains the same section.
- Group Policy templates (ADMX with English and German ADML) and the registry script
  `Set-TypeWhisperPolicy.ps1` are attached as `TypeWhisper-win-PolicyTemplates.zip`.
  The [deployment guide](https://github.com/TypeWhisper/typewhisper-win/blob/main/docs/enterprise/windows-managed-settings.md)
  describes every key, Group Policy and Intune, network hosts, the microphone
  permission and packaging.

## Machine-wide installation

- Each release now also ships an MSI, `TypeWhisper-win-x64-rc.msi` for this release
  candidate. It installs TypeWhisper once for all users into
  `C:\Program Files\TypeWhisper`, with Start menu and desktop shortcuts for all users.
  Settings, models and plugins stay in each user's profile.
- A machine-wide installation is updated by the deployment: the app does not install
  app updates itself and locks the update channel. Plugin updates are unaffected.
- A silent MSI installation does not install the .NET 10 runtime. Deploy it first; the
  guide lists the commands. An interactive installation offers to install it.

## Other changes

- After an update, a short overview of new features appears once on a normal start.
  It never opens during a dictation, and Account & about > What's new in TypeWhisper
  shows it again.
- Select lists with ten or more choices, such as the spoken language, have a search
  field. It ignores case and accents and also finds language codes.
- The overlay offers the icon of the app you dictate into as its own widget, separate
  from the app name.
- The tray menu follows the Light theme.
- Clicking a recent transcription on Home opens it in History. Recent rows have Copy
  and Open in History in their context menu, and the History context menu acts on the
  row it was opened on.
- Regex corrections in the dictionary keep their own identity through sync with
  macOS, imports and backups, so patterns such as `\d` and `\D` no longer overwrite
  each other.
- Failed plugin settings actions are recorded in the diagnostic log, without content.

## Updating

- 1.1 installations on the release-candidate channel are offered rc.1 through the
  update notice. Download and restart installs it and keeps the profile, plugins and
  settings. The app's update component moves to a new version with this release.
- Installations of TypeWhisper 1.0 on the release-candidate channel update to rc.1
  directly and import their existing data on the first start, as with 1.1.
- Installations on the Stable channel stay on 1.1.0 until 1.2.0 is published.

## Installation and requirements

- The per-user installer, the MSI and the portable ZIP are available for x64. Setup
  installs the .NET 10 runtime when it is missing; the portable ZIP requires it
  separately.
- TypeWhisper requires Windows 10 build 19041 or later.
- As with 1.1, the GitHub installers, including the MSI, are not code-signed, so
  Windows SmartScreen may ask for confirmation. The Microsoft Store version is updated
  separately.

## RC validation notes

- Update an installed 1.1.0 on the release-candidate channel to rc.1 through the
  update notice and check the restart, shortcuts, license, profile, plugins and
  dictation. Then update rc.1 to the next 1.2 build the same way.
- Install the MSI silently on a device with the .NET 10 runtime, start TypeWhisper as
  a standard user, upgrade with the next release candidate's MSI and uninstall it.
- Import the templates from `TypeWhisper-win-PolicyTemplates.zip` into the Group
  Policy editor, set a few policies and compare them with Settings > Advanced >
  Managed settings.
- The overview of new features appears once after the update and not during a
  dictation.
