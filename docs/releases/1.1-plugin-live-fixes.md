# Plugin live-test fixes, 2026-09-10

Two issues reproduced through the running Windows development app's HTTP API are corrected in this change.

## Translated API segments

An English fixture transcribed with Groq Whisper Large V3 Turbo and translated with the configured Groq GPT-OSS 20B returned German overall text, but English JSON segments and English SRT/VTT subtitles.

The host now translates segment text in batches of at most 32 entries, splitting batches above 8,000 source-text characters (an individually longer segment occupies its own batch). Stable numeric IDs enforce the original count and order; provider timestamps remain unchanged. Malformed, empty, missing or reordered segment output fails with HTTP 502 instead of exposing source-language subtitles. Cancellation discards partial results. Dictionary corrections run after translation. Whole-transcript translation remains separate so prior acoustic refinements, context and paragraphs are preserved.

This adds segment-translation LLM calls for timed results. Untimed results keep whole-text translation and still cannot produce timestamped subtitles. The change does not synthesize word-level alignment in the target language.

## Deepgram language capabilities

The portable Deepgram plugin exposed no supported-language metadata, so the host rejected explicit `language=en` before contacting Deepgram. Automatic detection succeeded on the same fixture.

Portable Deepgram 1.1.3 now exposes model-specific language codes and model metadata based on [Deepgram's language documentation](https://developers.deepgram.com/docs/models-languages-overview), checked on 2026-09-10. Capabilities follow model selection and restored preferences. This changes the portable package only; legacy plugin code and the public catalogs are untouched.

## Validation

- All 1,220 presentation tests and 24 portable Deepgram tests passed. Regression coverage includes translated JSON/SRT/VTT, timestamp preservation, batching, invalid alignment, cancellation, untimed output, unchanged main-text refinements/paragraphs, model switching and registry capability refresh.
- The required Windows development helper built and launched the checkout. The corrected Deepgram 1.1.3 package was staged in the development profile with the previous package/index backed up outside the profile; startup accepted it.
- Real Groq API requests produced German overall text and German segments in JSON, SRT and VTT. The two fixture intervals remained `0–3.26` and `4.16–6.24` seconds.
- Real Deepgram Nova-3 and Nova-2 requests succeeded with explicit English and German. The German test reused the user's spoken test sentence. Nova-2 reproduced it exactly; Nova-3 returned singular “Änderung” instead of plural “Änderungen,” a recognition-quality observation rather than a language-selection failure.
- Nova-2 with explicit Arabic was correctly rejected with HTTP 422. Request-scoped overrides restored the original active Groq Turbo selection.

These are short x64 development tests, not ARM64 execution, long-audio acceptance or a public plugin release. No credentials were exported.
