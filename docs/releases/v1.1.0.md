# TypeWhisper v1.1.0

TypeWhisper 1.1.0 is the new Windows release. The app is rebuilt on WinUI 3 and
follows the layout of TypeWhisper for macOS, and every transcription, text and
speech provider is now a portable plugin. Installations of TypeWhisper 1.0
update in place and import their existing data on the first start.

## Highlights

- Settings is the main window, with the macOS sidebar, a Home dashboard and
  Dictionary, Snippets, Workflows, Recorder and File transcription in one place.
  History opens in its own window. A Theme setting offers System, Light and Dark.
- The interface is available in English, German, Japanese and Simplified
  Chinese. It follows the Windows display language on the first start and can be
  changed in Settings.
- Providers are installed on demand from Integrations. Plugin updates appear
  next to app updates; unless turned off, they are downloaded in the background
  and applied at the next start.
- Workflows run in matching apps and websites or from their own shortcut. They
  can set the spoken language and the task, including native translation to
  English, and dictation shortcuts can also use their own transcription model.
  A workflow palette runs workflows on the selected text, and "Press Enter after
  inserting" offers the four macOS modes.
- An optional local HTTP API and a bundled command-line client control the
  running app. Advanced settings lists the Raycast extension and the browser
  extension for Chrome and Firefox, which reports the active tab for website
  workflows.

## Dictation

- Escape cancels a recording or its transcription.
- The microphone opens while the model is still loading, so the start of a
  dictation is kept.
- A new "Paste last transcription" shortcut (unassigned by default) and tray
  item insert the last dictation again.
- Audio ducking lowers other apps instead of the output volume, so feedback
  sounds and spoken feedback keep their level.
- Shortcuts sent by gesture and macro tools such as AutoHotkey work, and AltGr
  characters stay typeable with Ctrl+Alt shortcuts.
- A microphone test and live microphone status explain capture problems.
  After the Windows default microphone changes, the next recording uses the
  new one instead of repeating the old error.
- "Paste only into the original field" handles combobox search fields and
  terminals and falls back to the window when no field is found.

## Local models

- Parakeet, Whisper (Local) and Qwen3 ASR run in a separate worker process. A
  crash ends only that process, and the transcription is retried.
- NVIDIA Parakeet offers Parakeet Ultra 0.6B as the recommended model. On x64
  it runs on NVIDIA, AMD and Intel graphics cards through Vulkan.
- Qwen3 ASR (Local) transcribes on the CPU with a 0.6B or 1.7B model.
- Dictionary terms boost Parakeet dictations of up to five minutes and are
  passed to local Whisper as its prompt.
- A Local LLM plugin runs Gemma 4, Qwen3.5 and LFM2.5. A local model can
  suggest dictionary aliases.
- Parakeet, Whisper (Local), Qwen3 ASR and Local LLM models are unloaded when
  idle, after a configurable delay (10 minutes by default).
- Parakeet, Whisper (Local), Qwen3 ASR and Cohere Transcribe check the free
  disk space before downloading a model.

## Data, updates and support

- Sync & backup can export your TypeWhisper data into one ZIP or delete all of
  it. The export leaves out API keys, licenses, sign-ins, models and installed
  plugins.
- With a commercial license, History syncs with TypeWhisper for macOS through
  a shared cloud folder.
- Setup can import words, corrections and snippets from Wispr Flow and custom
  words from Handy.
- TypeWhisper checks for updates a minute after startup and then daily, and
  offers Download and restart, Later or Skip this version.
- Release builds keep a diagnostic log without dictated content, and a JSON
  support report can be exported.

## Upgrading from 1.0

TypeWhisper 1.0.9 offers 1.1.0 through its update check. On the first start
without a 1.1 profile, TypeWhisper copies dictionary entries, snippets,
workflows and history text, converts supported recording and text preferences,
keeps the license, transfers plugin settings and encrypted API keys, installs
compatible plugins and copies available model files. The 1.0 profile stays
unchanged; returning to 1.0 uses it, and changes made in 1.1 are not copied
back.

- Account sign-ins, archived recordings and audio, recovery audio, automation
  and sync settings, and settings without a 1.1 equivalent stay in the 1.0
  profile.
- Missing providers are reported; TypeWhisper does not choose a replacement.
- If the local HTTP API required a token, 1.1 issues a new one. The bundled
  command-line client finds it on its own; scripts that used the 1.0 token need
  to read it again. The Raycast extension works only with Require API token
  turned off.
- Installing migrated plugins needs internet access.

## Release candidate users

1.1.0 contains the same changes as 1.1.0-rc.2. Installations on the Release
Candidate channel stay on rc.2 until the next release candidate; choose Stable
as the update channel in Account & about to update to 1.1.0 and receive later
stable updates.

## Installation and requirements

- The installer and portable ZIP are available for x64. Setup installs the
  .NET 10 runtime when it is missing; the portable ZIP requires it separately.
- There is no ARM64 build anymore. ARM64 installations of 1.0 from GitHub stay
  on 1.0.9. Windows 11 on Arm can run the x64 version through emulation, which
  is untested.
- TypeWhisper requires Windows 10 build 19041 or later.
- As with 1.0.9, the GitHub installers are not code-signed, so Windows
  SmartScreen may ask for confirmation. The Microsoft Store version is updated
  separately.
